## 📌 Project Overview

A menu-driven C application designed to manage student records efficiently using structures and file handling.

## ✨ Key Features

- ➕ Add Student Records
- 📋 Display Student Records
- 🔍 Search Student by ID
- ✏️ Update Student Details
- 🗑️ Delete Student Records
- 💾 Permanent Data Storage

## 🛠️ Technologies Used

- C Programming
- Structures
- File Handling
- Clang Compiler

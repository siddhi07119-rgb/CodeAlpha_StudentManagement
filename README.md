# Student Management System

A simple Student Management System developed using C programming.

## Features
- Add Student Records
- Display Student Records
- Search Student by ID
- Store records using File Handling

## Technologies Used
- C Programming
- File Handling

## How to Run

Compile:
clang student.c -o student

Run:
./student
